# 查看与识别文件

资料库中的文件需要被快速找到、识别、预览。本节介绍搜索、筛选、预览、识别文件的各种方法。

## 一句话理解

**资料库的"找文件"能力 = 搜索 + 筛选 + 预览。**

## 搜索文件

### 搜索框

资料库顶部有搜索框，输入关键词即可搜索：

- 搜索范围：文件名、文件内容（限于文本类文件）。
- 搜索方式：实时搜索，输入即查。
- 命中显示：相关文件会高亮关键词。

### 搜索技巧

- **按文件名搜索**：`PRD-采购` 会找到文件名含"PRD"和"采购"的文件。
- **按内容搜索**：在文本类文件（Word、PDF、Markdown）中，搜索词会匹配正文。
- **多个关键词**：用空格分隔，所有关键词都需命中。
- **精确匹配**：用双引号包围关键词，例如 `"采购订单审批"`。

### 搜索结果展示

- 文件名命中：文件名高亮。
- 内容命中：搜索结果下方显示命中片段，前后带省略号。
- 命中片段点击跳转到文件预览页对应位置。

## 筛选文件

资料库提供多种筛选维度：

### 来源筛选

| 选项 | 说明 |
| --- | --- |
| 全部 | 所有文件 |
| 用户上传 | 你自己上传的 |
| 系统生成 | TestAgent 生成的产物 |

### 文件类型筛选

| 选项 | 说明 |
| --- | --- |
| 全部 | 所有类型 |
| 图片 | 图片类（png、jpg、jpeg、webp、gif） |
| 文档 | Word、PDF、Markdown、TXT |
| 表格 | Excel |
| 演示 | PowerPoint |

### 范围筛选

| 选项 | 说明 |
| --- | --- |
| 当前 | 资料库活跃文件 |
| 最近删除 | 已删除但可恢复的文件（30 天内） |

筛选可通过资料库顶部筛选按钮打开。

## 视图模式

资料库支持两种视图：

### 网格视图（默认）

- 文件以卡片形式展示。
- 每张卡片显示文件名、缩略图、修改时间、大小。
- 适合快速浏览、视觉识别。

### 列表视图

- 文件以行列表展示。
- 每行显示文件名、修改时间、大小。
- 适合大量文件、详细信息查看。

切换视图：点击资料库右上角的网格/列表图标。

## 文件预览

### 预览入口

- 网格视图：点击文件卡片。
- 列表视图：点击文件行。
- 搜索结果：点击命中片段。

### 预览内容

#### Word 文档

- 按章节结构渲染。
- 标题样式保留（一级、二级标题）。
- 表格按原样显示。
- 图片直接嵌入显示。

#### PDF

- 分页渲染。
- 支持翻页。
- 支持缩放。

#### Markdown / TXT

- 按 Markdown 语法渲染。
- 代码块、表格、列表都按标准显示。

#### Excel

- 按工作表分页。
- 单元格内容按格式渲染。

#### 图片

- 直接显示。
- 支持缩放。

### 预览操作

- **下载**：在预览页右上角点击【下载】。
- **在新聊天中使用**：在预览页点击【在新聊天中使用】，把文件附加到新对话。
- **删除**：在预览页点击【删除】。

## 文件的"识别"信息

每个文件卡片或详情页显示以下识别信息：

| 信息 | 说明 |
| --- | --- |
| 文件名 | 显示名 |
| 扩展名 | 文件类型 |
| 文件大小 | KB / MB |
| 修改时间 | 上次修改时间 |
| 创建时间 | 上传时间 |
| 来源 | 用户上传 / 系统生成 |
| 预览状态 | 已生成 / 生成中 / 失败 |
| 文件 ID | 内部唯一标识 |

## 文件的"最近删除"分类

已删除的文件不会立刻消失，而是移到"最近删除"分类：

- 可在 30 天内恢复。
- 30 天后自动永久删除。
- 列出删除时间、原始位置。

### 恢复文件

1. 切换到【最近删除】范围。
2. 找到目标文件。
3. 点击【恢复】。
4. 文件回到【资料库】活跃分类。

### 永久删除

- 在【最近删除】中点击【永久删除】。
- 立即清除（不等待 30 天）。
- 不可恢复。

## 多选与批量操作

### 多选模式

- 进入方式：点击资料库的"多选"按钮，或在文件上长按/右键。
- 选中后显示批量操作工具栏。

### 批量操作

- **下载**：把选中文件打包成 zip 下载。
- **删除**：批量移到【最近删除】。
- **创建新聊天**：用选中文件创建一个新对话。

## 排序

资料库支持多种排序：

- 修改时间（默认）：最新的在前。
- 创建时间：最近创建的在前。
- 文件名：按字母顺序。
- 大小：从大到小或从小到大。

切换排序：点击列头或排序下拉菜单。

## 分页

资料库采用分页加载：

- 默认每页 50 条。
- 可以切换页面大小。
- 支持无限滚动（拉到列表底部自动加载）。

## 搜索效率提升

### 文件名清晰的命名

文件命名带有关键词，便于搜索：

- ✅ `PRD-采购审批-v2.docx`
- ✅ `性能测试方案-订单模块.docx`
- ❌ `测试方案.docx`
- ❌ `new.docx`

### 文档内结构化

文档内结构化便于搜索命中：

- 使用清晰的标题。
- 关键词在标题或开头出现。
- 避免大段纯文本。

### 利用筛选而非搜索

如果你的目标文件类型明确：

- 先按"来源"筛选（只看"用户上传"）。
- 再按"类型"筛选（只看"Word 文档"）。
- 最后按时间倒序（最近上传的在前）。

通常比纯搜索更快。
