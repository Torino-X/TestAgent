# 上传资料库文件

资料库是 TestAgent 的"个人文件柜"。本节介绍如何把文件上传到资料库，以及上传时的注意事项。

## 一句话理解

**资料库 = 你的"测试文件柜"。**

把常用文件集中存储，避免每次重新上传。资料库的文件可以在新聊天中快速附加。

## 入口

### 入口 1：侧边栏 → 资料库 → 上传文件

- 顶部【上传文件】按钮。
- 弹窗中选择文件。

### 入口 2：拖拽上传

- 把文件直接拖到资料库页面。
- 系统自动开始上传。

### 入口 3：聊天输入框附件

- 在聊天输入框选择文件后，提示"是否保存到资料库"。

## 上传步骤

1. **点击【上传文件】**。
2. **选择文件**：支持多选，会并行上传。
3. **等待上传完成**：进度条会显示每个文件的上传进度。
4. **上传完成**：文件出现在资料库列表中，按修改时间倒序。

## 支持的文件格式

| 格式 | 扩展名 | 用途 |
| --- | --- | --- |
| Word 文档 | .docx, .doc | 需求文档、模板 |
| PDF | .pdf | 需求基线 |
| Markdown | .md | 需求、笔记 |
| 纯文本 | .txt | 笔记、要求 |
| Excel | .xlsx, .xls | 模板、数据 |
| 图片 | .png, .jpg, .jpeg, .webp, .gif | 原型图、流程图、截图 |

> 单文件大小通常不超过 30 MB；超过此大小的文件建议压缩或拆分。

## 上传后的预览

### Word / PDF / Markdown

上传后系统会自动生成预览：

- **Word 文档**：按章节结构渲染，识别标题层级。
- **PDF**：分页渲染为可读视图。
- **Markdown**：按 Markdown 语法渲染。
- **Excel**：按工作表分页渲染。
- **图片**：直接显示。

预览生成需要数秒，期间文件状态可能显示"预览生成中"。

### 预览生成失败的常见原因

- 文件已加密。
- 文件格式异常（如损坏的 docx）。
- 文件内容为空。
- 服务器临时故障。

预览失败不影响文件本身，仍可下载和用于生成。

## 文件分类

资料库支持按来源分类：

| 来源 | 说明 |
| --- | --- |
| 用户上传 | 你上传的文件 |
| 系统生成 | TestAgent 生成的产物 |

筛选来源：

- 点击筛选按钮。
- 选择"用户上传"或"系统生成"。
- 点击确认。

## 文件类型筛选

资料库支持按文件类型筛选：

- **全部**：显示所有文件。
- **图片**：图片类。
- **文档**：Word、PDF、Markdown、TXT。
- **表格**：Excel。
- **演示**：PowerPoint（如果支持）。

筛选位于资料库顶部的筛选弹窗。

## 上传的最佳实践

### 命名规范

- 文件名带上版本号：`PRD-v2.3-采购审批.docx`。
- 文件名带上日期：`性能测试-2026-09-15.pdf`。
- 避免特殊字符（避免 emoji、空格过多的命名）。
- 同类文件保持命名模式一致。

### 文件归档

按用途分类归档：

| 文件夹式命名 | 示例 |
| --- | --- |
| 按项目 | `采购系统-2026Q3-PRD.docx` |
| 按需求类型 | `功能测试-通用-PDF.md` |
| 按版本 | `PRD-v1`、`PRD-v2` |

### 上传时机

- **项目开始时**：上传项目级资料。
- **新需求来时**：上传新需求文档。
- **定期整理**：清理过时文件，保留当前版本。

### 避免上传

- ❌ 含敏感信息的文件（如客户数据、未公开的财务数据）。
- ❌ 临时文件（如截图占位）。
- ❌ 重复文件（同一份文件不要上传多次）。

## 文件名冲突处理

资料库允许同名文件存在，但会带上数字后缀区分：

- 第一次上传 `测试方案.docx` → `测试方案.docx`
- 再次上传 `测试方案.docx` → `测试方案 (1).docx`

建议上传前确认是否已有同名文件，避免混淆。

## 上传后的批量操作

上传多个文件后，可以批量操作：

- **全选**：点击列表头的勾选框。
- **下载**：批量下载选中文件（打包成 zip）。
- **删除**：批量移到"最近删除"。
- **创建新聊天**：用选中的文件创建一个新对话。

## 与"项目资料"的区别

| 维度 | 资料库 | 项目资料 |
| --- | --- | --- |
| 范围 | 个人 | 项目 |
| 复用 | 跨对话 | 仅项目内 |
| 删除 | 软删除（30 天可恢复） | 解除关联（不删除原文件） |
| 适合 | 个人常用文件 | 项目专属文件 |

**实践建议**：

- 个人常用文件（个人 PRD 模板、个人规范）→ 资料库。
- 项目专属文件（项目 PRD、项目设计）→ 项目资料（从资料库关联）。

## 上传失败排查

### 常见失败原因

- **文件过大**：超过限制会被拒绝。
- **网络中断**：上传过程中断网。
- **格式不支持**：上传了不支持的格式。
- **权限不足**：某些文件需要管理员权限。

### 排查步骤

1. 检查文件大小。
2. 检查文件扩展名。
3. 检查网络连接。
4. 重试上传。
5. 如持续失败，联系管理员。
