# 管理资料库文件

资料库中的文件需要长期维护：重命名、下载、删除、恢复。本节介绍各种管理操作的入口、效果与注意事项。

## 一句话理解

**管理文件 = 重命名 + 下载 + 删除 + 恢复。**

四个核心操作覆盖了文件生命周期的所有维护场景。

## 重命名文件

### 入口

- 列表/网格视图中：点击文件的【更多】菜单（三个点）→【重命名】。
- 文件预览页：右上角【重命名】。

### 重命名步骤

1. 弹出重命名对话框。
2. 修改文件名（保留扩展名）。
3. 点击【确认】。

### 命名建议

- 带上版本号：`PRD-v2.3-采购审批.docx`。
- 带上日期：`测试方案-2026-09-15.docx`。
- 带上项目：`采购系统-性能测试方案.docx`。
- 避免特殊字符（emoji、`#`、`/`、`\` 等）。
- 命名长度建议 5–50 个字符。

### 重命名的限制

- 文件名不能为空。
- 文件名不能与现有文件重复（如果开启去重）。
- 同一文件可在 30 天内多次重命名。

## 下载文件

### 下载入口

- 列表/网格视图中：点击文件的【更多】菜单 →【下载】。
- 文件预览页：右上角【下载】。
- 批量下载：多选文件 →【下载】（打包成 zip）。

### 下载后的文件

- 文件名沿用资料库的显示名。
- 文件内容与预览一致（除非上传后做了修改）。
- 下载的文件可独立使用 Word/WPS/Excel 打开。

### 批量下载

- 选中多个文件。
- 点击【下载】。
- 系统自动打包成 zip 下载。

批量下载适合：

- 归档多个文件。
- 跨设备同步。
- 备份资料库。

## 删除文件

### 软删除（默认）

点击【删除】按钮：

- 文件从【资料库】活跃列表移除。
- 移到【最近删除】分类。
- 30 天内可恢复。
- 30 天后自动永久删除。

### 软删除的影响

- 已生成的测试方案不会受影响（产物是独立的）。
- 已发起的对话也不会受影响（附件已固化）。
- 但文件不再能被附加到新对话。

### 永久删除

在【最近删除】中：

1. 找到目标文件。
2. 点击【永久删除】按钮。
3. 确认操作。

永久删除的文件无法恢复。

:::warning
永久删除前请确认：
- 不再有对话或项目依赖该文件。
- 已在本地或其他位置做好备份。
- 文件内容没有需要保留的价值。
:::

## 恢复文件

### 恢复入口

- 切换到【最近删除】范围。
- 找到目标文件。
- 点击【恢复】按钮。

### 恢复后

- 文件回到【资料库】活跃列表。
- 原始元数据保留（文件名、修改时间）。
- 可重新在新对话中附加。

### 恢复的限制

- 只能在 30 天内恢复。
- 超过 30 天的文件已自动永久删除，无法恢复。

## 移动与归档

资料库不提供"文件夹"概念，所有文件平铺。如需分类管理，可以：

- **用文件名分类**：`采购-`、`财务-`、`HR-` 等前缀。
- **用搜索/筛选**：按类型、来源筛选。
- **用本地目录**：下载后用本地文件夹管理。

## 跨设备同步

资料库的文件存储在服务端：

- 在不同设备登录同一账户，资料库内容一致。
- 但不支持离线访问（需要网络）。
- 如需离线使用，下载到本地。

## 文件生命周期

### 正常流程

```
上传 → 使用（附加到对话）→ 完成使命 → 下载归档或删除
```

### 异常流程

- 上传后立刻删除（误传）：可立即在【最近删除】恢复。
- 上传错误文件：删除 → 重新上传正确版本。
- 文件已删除但对话仍引用：对话仍可访问产物，但不能再附加该文件到新对话。

## 多选与批量管理

### 进入多选模式

- 资料库工具栏点击【多选】按钮。
- 或在文件上长按/右键。

### 批量操作

| 操作 | 说明 |
| --- | --- |
| 全选 | 选中当前页所有文件 |
| 反选 | 取消所有已选，改为选中未选 |
| 批量下载 | 打包成 zip 下载 |
| 批量删除 | 全部移到【最近删除】 |
| 创建新聊天 | 用选中文件创建一个新对话 |

### 批量删除的注意事项

- 一次可删除任意数量的文件。
- 删除是不可逆的"软删除"，30 天内可恢复。
- 永久删除需要逐个操作或在【最近删除】批量执行。

## 文件元数据

每个文件维护以下元数据：

| 字段 | 说明 |
| --- | --- |
| 文件 ID | 内部唯一标识 |
| 文件名 | 显示名 |
| 扩展名 | 文件类型 |
| 大小 | 文件字节数 |
| MIME 类型 | 内容类型 |
| 创建时间 | 上传到资料库的时间 |
| 修改时间 | 内容最近修改时间 |
| 来源 | 用户上传 / 系统生成 |
| 预览状态 | 已生成 / 生成中 / 失败 |
| 关联对话数 | 引用该文件的对话数 |
| 删除时间 | 软删除的时间 |

元数据用于：

- 列表展示。
- 排序与筛选。
- 排查问题时定位。

## 存储空间管理

### 配额

资料库的存储空间取决于：

- 个人版：通常 5–10 GB。
- 团队版：通常 100 GB+。

具体配额以系统显示为准。

### 空间清理建议

- 定期删除【最近删除】中的文件。
- 删除长期未用的文件（可先用筛选找到）。
- 大文件优先处理（视频、大文档）。

### 空间不足的影响

- 上传新文件会失败。
- 系统生成的文件可能无法保存。
- 已有文件不受影响。

## 协作与权限

### 个人文件 vs 团队文件

| 类型 | 可见范围 |
| --- | --- |
| 个人文件 | 仅自己可见 |
| 团队文件 | 团队成员可见 |

具体取决于账户类型与权限设置。

### 权限操作

- 查看：通常所有人可查看自己上传的文件。
- 编辑：仅文件所有者或管理员可编辑（重命名）。
- 删除：仅文件所有者或管理员可删除。

## 常见管理场景

### 场景 1：清理旧需求

1. 按"修改时间"升序排序。
2. 找到 6 个月前未使用的文件。
3. 下载关键文件作为本地归档。
4. 删除剩余文件。

### 场景 2：整理项目文件

1. 用筛选按"类型"筛选（如只看 Word 文档）。
2. 按文件名搜索（如 `采购`）。
3. 重命名为带前缀的命名规范。
4. 保留核心版本，删除中间版本。

### 场景 3：临时文件清理

1. 切换到【最近删除】。
2. 查看 30 天内删除的文件。
3. 恢复需要的文件。
4. 永久删除剩余文件。
