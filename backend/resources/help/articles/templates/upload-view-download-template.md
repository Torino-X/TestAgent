# 上传、查看与下载模板

模板的"上传、查看、下载"是三个基础操作。本节介绍它们的入口、参数、限制与典型场景。

## 上传模板

### 入口

- **模板市场** → 顶部【上传模板】按钮。
- **我的模板** → 右上角【上传】按钮。

### 上传步骤

1. **选择文件**：点击文件选择框，选中 .docx 或 .xlsx 文件。
2. **填写模板名称**：模板显示名，会出现在卡片和搜索结果中。
3. **选择分类**：从下拉菜单中选择（功能测试、性能测试、安全测试等）。
4. **填写描述**：一两句话说明模板的用途、适用场景、特殊约定。
5. **添加标签**：多个标签用逗号分隔，便于搜索。
6. **选择是否发布到模板市场**：
   - 不勾选：仅你自己可用。
   - 勾选：团队成员也能在【模板市场】中看到。
7. **点击【上传】**：模板进入【我的模板】。

### 支持的文件格式

| 格式 | 扩展名 | 用途 |
| --- | --- | --- |
| Word 文档 | .docx | 最常用，推荐 |
| Excel 工作簿 | .xlsx | 适合测试用例模板 |

### 上传限制

- 文件大小：通常不超过 30 MB。
- 文件需可正常打开（未损坏、未加密）。
- 文件中需要包含至少 3 个一级章节。

### 上传后的验证

上传成功后，建议立即：

1. 打开【我的模板】找到新上传的模板。
2. 点击进入预览页。
3. 检查章节识别是否正确（一级、二级标题层级清晰）。
4. 如果识别异常，可能需要调整模板文件结构（见 [如何设计适合 TestAgent 的模板](/help/article/template-design)）。

## 查看模板

### 查看入口

- **【我的模板】**：你保存或上传的所有模板。
- **【模板市场】**：所有公开或团队发布的模板。

### 查看方式

#### 1. 卡片列表

默认以卡片网格展示，每张卡片包含：

- 模板名称
- 分类与标签
- 作者
- 版本号
- 文件大小
- 上传/保存时间
- 快捷操作按钮（预览、下载、保存、使用）

#### 2. 搜索与筛选

- **搜索框**：按名称、描述、标签搜索。
- **筛选**：按分类（功能、性能、安全等）。
- **排序**：按上传时间、保存次数、文件大小等。

#### 3. 模板详情页

点击模板卡片打开详情页：

- **缩略图**：首页渲染图。
- **完整预览**：按章节结构渲染。
- **元数据**：作者、版本、大小、标签、上传时间。
- **PDF 预览**：完整 PDF 渲染，浏览真实排版。
- **操作按钮**：保存、下载、使用、发布、删除。

### 查看时的注意事项

- **预览不消耗额度**：可以放心浏览。
- **PDF 预览可能略有延迟**：模板文件较大时，PDF 渲染需要数秒。
- **预览可能与 Word 不完全一致**：复杂排版（嵌套表格、宏）在 PDF 预览中可能简化显示。

## 下载模板

### 下载入口

- **【我的模板】**卡片 → 【下载】按钮。
- **模板详情页** → 【下载】按钮。

### 下载文件

下载的文件是模板原文件，格式与上传时一致：

- .docx：用 Word/WPS/Pages 打开。
- .xlsx：用 Excel/WPS/Sheets 打开。

### 下载用途

- **本地归档**：把核心模板备份到本地。
- **二次修改**：下载后用 Word 修改章节结构，重新上传为新版本。
- **跨团队分享**：在不开放模板市场的场景下，通过文件分享模板。
- **离线分析**：用 Word 工具检查模板结构是否符合规范。

### 下载后如何处理？

- 文件名沿用原模板名，建议改名加上版本和日期。
- 修改时务必保留标题样式。
- 修改完成后重新上传，保留为新版本（不要覆盖原版本，避免破坏引用关系）。

## 常见操作流程

### 流程 1：上传新模板并发布到市场

```
打开模板市场 → 点击【上传模板】
  → 选择文件
  → 填写名称、分类、描述、标签
  → 勾选"发布到模板市场"
  → 点击【上传】
  → 验证章节识别
  → 通知团队成员保存
```

### 流程 2：升级现有模板

```
打开【我的模板】 → 下载旧版本
  → 用 Word 修改
  → 重新上传（命名带版本号 v2）
  → 在元数据中标注为新版
  → 通知使用旧版的对话/项目
```

### 流程 3：从市场保存并使用

```
打开【模板市场】 → 浏览或搜索模板
  → 点击【保存模板】
  → 打开【我的模板】确认
  → 在新聊天中选择该模板
```

### 流程 4：分享给团队成员

```
方案 A：发布到模板市场，成员自行保存
方案 B：下载文件，通过 IM/邮件发送给成员，成员自行上传
```

## 常见问题

### 上传后章节识别错误？

- 检查文件是否使用了 Word 标题样式。
- 检查章节层级是否清晰（一级、二级）。
- 避免合并单元格与跨页大表。

### 上传后看不到模板？

- 刷新页面。
- 检查筛选条件（可能筛选到了"已发布"或"我上传的"）。
- 检查文件是否上传成功（看【我的模板】列表）。

### 下载后无法打开？

- 文件可能损坏，建议重新上传。
- 检查文件扩展名是否正确（.docx 而非 .doc）。
- 用 WPS/Pages 替代 Word 试试。

### 模板与生成结果不一致？

- 模板设计时是否清晰定义了章节。
- 章节确认时是否误选了"保留原样"。
- 自动审查可能提示需要重新生成。
