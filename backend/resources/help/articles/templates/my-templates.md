# 我的模板

"我的模板"汇集了你保存或上传的所有模板，是新聊天中可直接选择的模板集合。本节介绍如何管理、使用、归档这些模板。

## 一句话理解

**"我的模板" = 你专属的测试方案模板库。**

新聊天中选择模板时，默认从这里选择。

## 入口与界面

### 入口

- **侧边栏 → 模板市场 → "我的模板"标签**
- **新聊天中的模板选择弹窗**

### 界面元素

- **筛选**：按分类（功能、性能、安全等）。
- **搜索**：按名称、描述、标签搜索。
- **排序**：按来源（市场保存 / 自己上传）。
- **卡片信息**：名称、分类、作者、版本、文件大小、保存日期。

## 模板来源

"我的模板"中有两种来源的模板：

### 1. 从模板市场保存

- 来源标签：市场。
- 模板市场中有【已保存】标记的，都在这里。
- 你无法修改这些模板的内容，但可以下载、归档。

### 2. 自己上传

- 来源标签：我上传的。
- 上传时填写了名称、分类、描述、标签。
- 可以管理发布状态、编辑元数据（不可修改文件内容）。

## 管理操作

### 查看详情

点击模板卡片：

- 预览完整内容（按章节结构渲染）。
- 查看元数据（作者、版本、文件大小、上传时间）。
- 查看保存/上传时间。

### 预览 PDF

模板预览支持完整 PDF 渲染，帮你直观看到：

- 模板首页排版。
- 章节层级。
- 表格样式。

预览不消耗 LLM 额度。

### 下载模板

点击【下载】按钮，把模板文件保存到本地：

- 文件名沿用模板原文件名。
- 下载的文件可以归档、复用、修改后重新上传。

### 发布到模板市场（仅自己上传的模板）

把模板发布到模板市场，让团队其他成员也能看到并保存：

1. 点击模板卡片的【更多】菜单。
2. 选择【发布到市场】。
3. 发布成功后，模板出现在【模板市场】的"我发布的"分类中。

:::warning
发布前请确认模板不包含敏感信息（旧项目数据、内部编号、未公开规范等）。发布后所有成员可见。
:::

### 取消发布

把已经发布到市场的模板撤回：

1. 在【我的模板】中找到对应模板。
2. 点击【更多】菜单。
3. 选择【取消发布】。

取消发布后，模板市场不再展示该模板，但已保存的成员仍可继续使用他们已保存的副本。

### 删除模板

从【我的模板】中删除：

1. 点击模板卡片的【更多】菜单。
2. 选择【删除】。
3. 确认删除。

:::warning
删除模板不影响已经使用该模板生成的历史测试方案，但后续新聊天中无法再选择该模板。建议删除前先确认是否有项目还在依赖。
:::

### 编辑元数据

对自己上传的模板，可以编辑：

- 名称
- 分类
- 描述
- 标签

不能编辑：

- 文件内容（必须重新上传）。

## 在新聊天中使用

新聊天中发起测试方案生成时：

1. 点击输入框的【附件】按钮。
2. 选择【模板】或类似入口。
3. 在弹窗中选择【我的模板】标签。
4. 选择目标模板并附加到对话。
5. 发起生成时系统会按模板结构填充内容。

## 模板数量与组织建议

### 推荐数量

建议保持 3–10 份核心模板：

- 太多：选择困难，维护成本高。
- 太少：覆盖范围不够。

### 组织方式

可以按"测试类型"组织：

| 模板 | 适用 |
| --- | --- |
| 通用功能测试模板 | 大多数需求 |
| 性能测试专项模板 | 性能专项 |
| 安全测试专项模板 | 安全专项 |
| 数据迁移测试模板 | 数据迁移类需求 |
| 合规测试模板 | 合规/审计类需求 |

也可以按"项目类型"组织（如果业务领域固定）：

| 模板 | 适用 |
| --- | --- |
| 采购系统测试模板 | 采购相关需求 |
| 财务系统测试模板 | 财务相关需求 |
| 客户系统测试模板 | 客户相关需求 |

### 命名建议

模板名应一目了然：

- ✅ "通用功能测试方案模板"
- ✅ "金融系统性能测试模板"
- ❌ "模板 v1"
- ❌ "新版"
- ❌ "测试"

## 与"模板市场"的关系

- **模板市场**：所有人可见，含你发布、未发布的模板。
- **我的模板**：只对你可见。

当你保存或上传模板时，两个区域互相不影响：

- 保存到"我的模板"不会自动发布到"模板市场"。
- 上传到"我的模板"时勾选"发布到市场"，才会出现在"模板市场"中。

## 模板升级与多版本

模板通常会随业务迭代升级：

- **升级方式**：上传新版本（在模板元数据中保留版本号）。
- **版本号建议**：v1、v2、v3 或 2026-Q1、2026-Q2。
- **旧版本处理**：新版本上线后，旧版本可以归档（下载到本地）或保留作为对比。
- **生成时使用**：新聊天用最新版本；老聊天用老版本（保留历史一致性）。
