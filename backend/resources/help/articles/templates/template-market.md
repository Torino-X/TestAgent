# 模板市场

模板市场是 TestAgent 内置的高质量模板集合，可以浏览、预览、保存到"我的模板"。本节介绍如何用模板市场找到合适的模板。

## 一句话理解

**模板市场 = 测试模板的"应用商店"。**

和移动应用类似：

- 浏览：看有哪些模板可用。
- 预览：看模板长什么样。
- 保存：把模板装到自己的"我的模板"里。
- 使用：在新聊天中调用。

## 模板市场的两大区域

### 1. 模板市场（默认 Tab）

收录**所有团队发布**的模板。适合：

- 发现行业内常见测试方案结构。
- 借鉴其他团队的模板设计。
- 寻找你团队尚未覆盖的测试类型模板。

### 2. 我的模板

收录**你自己保存或上传**的模板。适合：

- 在新聊天中选择已确定的模板。
- 管理自己团队的私有模板。
- 上传自己的 Word/Excel 模板。

## 浏览模板

### 筛选方式

模板市场提供多种筛选维度：

- **分类**（顶部导航）：按行业、测试类型等分类，例如"功能测试""性能测试""安全测试"。
- **搜索框**：按模板名称、描述、标签搜索。
- **排序**：最新发布 / 最受欢迎 / 下载次数。

### 卡片信息

每个模板以卡片形式展示，关键信息包括：

- 模板名称
- 分类与标签
- 简短描述
- 作者与发布日期
- 版本号与文件大小
- 保存次数

## 预览模板

点击模板卡片打开预览页：

- **缩略图**：模板首页的渲染图。
- **章节列表**：模板识别出的章节结构。
- **元数据**：作者、版本、大小、标签、保存次数。
- **预览 PDF**：把模板按 PDF 形式完整渲染，浏览真实排版。
- **保存按钮**：把模板保存到"我的模板"。

预览时不消耗 LLM 额度，可以放心浏览。

## 保存模板

当你看到合适的模板：

1. 点击模板卡片打开预览页。
2. 点击【保存模板】按钮。
3. 模板自动出现在【我的模板】中。
4. 之后所有新聊天都可以在"我的模板"中选择它。

> 保存是一次性的操作，不需要每次重复。已保存的模板会带上"已保存"标记。

## 上传自己的模板

如果没有现成模板，可以上传自己的 Word 或 Excel 模板：

1. 点击模板市场顶部的【上传模板】按钮。
2. 填写模板信息：
   - 模板名称
   - 分类
   - 描述
   - 标签（多个）
   - 是否发布到模板市场
3. 选择文件并上传。

上传后，模板进入【我的模板】。如果勾选了"发布到市场"，还会出现在【模板市场】中供其他成员使用。

### 上传要求

- 支持格式：.docx（推荐）、.xlsx。
- 文件大小：通常不超过 30 MB。
- 模板结构：见[如何设计适合 TestAgent 的模板](/help/article/template-design)。

## 在新聊天中使用模板

模板保存后，在新聊天中发起测试方案生成时：

1. 点击输入框的【附件】或【模板】图标。
2. 选择【我的模板】标签。
3. 选中已保存的模板。
4. 与需求文档一起附加到对话。
5. 发起生成时系统会自动识别模板结构。

## 模板市场的内容来源

模板市场中的模板来自：

- **平台官方收录**：TestAgent 团队整理的通用模板，覆盖常见测试类型。
- **团队发布**：你的团队中其他成员上传并发布的模板。
- **公开贡献**：经过审核的外部贡献模板。

不同模板的可用性取决于你的权限设置——私有模板只对团队成员可见。

## 何时选模板市场 vs 自己设计？

| 场景 | 建议 |
| --- | --- |
| 团队首次使用，没有现成模板 | 从模板市场选一份相近的，作为起点 |
| 有团队 Word 模板 | 上传到"我的模板"，无需发布 |
| 想尝试新结构 | 从模板市场保存多份，对比效果 |
| 需要特定行业模板（金融、医疗等） | 模板市场搜索关键词 |

## 模板市场的协作价值

模板市场的核心价值在**团队层面**：

- **统一规范**：所有成员用同一份模板，输出风格一致。
- **减少维护成本**：模板升级一次，永久生效。
- **新人上手快**：新人无需理解整套规范，按模板填空即可。
- **跨项目复用**：不同项目共用模板，团队认知一致。
