# 保存模板

从模板市场保存模板到"我的模板"是单次操作，之后所有新聊天都可以使用。本节详细介绍保存的入口、效果与管理。

## 一句话理解

**保存 = 把模板复制一份到你的私人收藏。**

保存的模板只对你可见，不会影响其他成员。

## 保存的入口

模板市场中所有未保存的模板都带【保存模板】按钮，入口有三处：

### 1. 模板卡片

在【模板市场】Tab 浏览时，每个模板卡片的右下角有【保存模板】或【已保存】按钮：

- 未保存：按钮高亮显示，文字为"保存模板"。
- 已保存：按钮置灰，文字为"已保存"，并带有"✓"标记。

### 2. 模板预览页

点击模板卡片进入预览页，右上角有【保存模板】按钮。

### 3. 批量搜索结果

如果你通过搜索找到多个模板，每个卡片都可以单独保存。

## 保存的步骤

1. **找到模板**：浏览或搜索模板。
2. **预览（可选）**：点击卡片打开预览页，查看章节结构和排版。
3. **点击【保存模板】**：模板自动添加到"我的模板"。
4. **在新聊天中使用**：打开新聊天，从【我的模板】选择已保存的模板。

整个保存过程瞬时完成，不消耗 LLM 额度。

## 保存后的行为

- **独立副本**：保存的模板是你自己的副本，原始模板的更新（如发布新版本）不会自动同步到你这里。
- **可重命名**：可以在【我的模板】中查看模板的版本与作者信息。
- **可下载**：已保存的模板可以下载到本地，作为归档备份。
- **可使用**：所有新聊天都可以在"我的模板"中选择该模板。

## 已保存与未保存的区别

| 维度 | 未保存 | 已保存 |
| --- | --- | --- |
| 出现在"模板市场" | ✅ | ✅ |
| 出现在"我的模板" | ❌ | ✅ |
| 能否在新聊天中使用 | ❌ | ✅ |
| 能否下载 | 仅预览 | ✅ |
| 能否查看完整内容 | 预览 PDF | 完整预览 + 下载 |

## 重复保存会怎样？

不会出错，但也没有必要：

- 同一个模板保存多次不会创建多个副本。
- 如果模板已经保存，再次点击【保存模板】按钮不会产生新条目，界面会提示"已保存"。

## 取消保存

当前版本不支持"取消保存"。如果某个模板不再需要，可以：

- 不再使用即可——已保存的模板不影响其他功能。
- 通过本地归档管理——只下载到本地的模板不占用云端空间。

## 保存后的版本管理

模板会持续迭代。当你保存的模板发布新版本时：

- 你的"我的模板"中仍然是旧版本（不会自动升级）。
- 模板市场会显示新版本。
- 如果想用新版本，重新保存即可。
- 不建议在新聊天中混用旧版和新版——可能让生成结果不稳定。

## 保存策略建议

### 少量精选

不建议保存所有看到的模板。建议：

- 保存 3–5 份核心模板，覆盖你最常用的测试类型。
- 临时探索的模板可以不保存，按需预览即可。

### 按项目分类

如果你的工作涉及多种类型（功能测试、性能测试、安全测试），可以按类型分别保存：

- `通用功能测试模板` — 用于大多数功能测试方案。
- `性能测试模板` — 用于性能专项。
- `安全测试模板` — 用于安全专项。

这样在新聊天中切换模板更直观。

### 团队统一

如果你的团队已发布内部模板，建议优先保存团队模板，而不是公开市场的模板。理由：

- 团队模板已经过内部评审，更符合规范。
- 团队模板会随业务迭代升级。
- 团队模板的字段命名更贴近团队术语。

## 保存后如何验证可用性？

保存后建议在测试对话中验证：

1. 发起一个新对话（不消耗真实需求）。
2. 附加一份简单需求文档 + 已保存的模板。
3. 观察章节识别是否正确。
4. 如果识别异常，检查模板是否符合 [如何设计适合 TestAgent 的模板](/help/article/template-design) 的要求。
