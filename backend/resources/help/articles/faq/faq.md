# 常见问题

本节汇总 TestAgent 使用过程中最常见的问题与解决方法。如果你遇到的问题不在此列，可以查看具体章节的详细文档，或联系团队支持。

## 一、配置与登录

### 1. 登录后看不到任何项目或对话？

**可能原因**：

- 账户未完成初始化（首次登录需要完善信息）。
- 浏览器缓存问题。

**解决方法**：

- 退出登录后重新进入。
- 清除浏览器缓存或换浏览器。
- 联系管理员确认账户状态。

### 2. 系统设置里的"模型连通性测试"失败？

**可能原因**：

- API URL 错误（协议、端口、路径）。
- API Key 错误或过期。
- 网络问题（VPN、防火墙）。
- 模型名称拼写错误。

**解决方法**：

- 核对 API URL（注意末尾是否需要 `/v1`）。
- 重新生成 API Key 并粘贴。
- 用 curl 命令测试连通性。
- 核对模型名称是否与服务商文档一致。

### 3. 图像能力（OCR / 视觉理解）怎么配置？

**位置**：系统设置 → 图像能力。

**配置项**：

- API URL（如阿里云 DashScope）。
- API Key。
- 模型名（如 qwen-vl-plus）。
- 超时秒数。

**注意事项**：

- 不是必须的，仅在需要 OCR / 图片理解时配置。
- 配错不影响普通文字资料的处理。

### 4. 知识库连接失败？

**可能原因**：

- 知识库服务地址错误。
- API Key 错误或过期。
- 知识库服务未启动。
- 网络不通。

**解决方法**：

- 在【知识库】→【设置】中点击【测试连接】。
- 核对 API URL 与 Key。
- 确认知识库服务状态。

## 二、生成测试方案

### 5. 发起生成后一直卡在"正在思考"？

**可能原因**：

- LLM 调用阻塞（服务无响应）。
- 上下文过长导致处理慢。
- SSE 连接断开。

**解决方法**：

- 等待 1–2 分钟，看是否恢复。
- 检查【系统设置】的 LLM 连通性。
- 刷新页面看是否能恢复（任务不会丢失）。
- 如果持续 5 分钟无响应，刷新页面重试。

### 6. 上传了文件但没识别为"需求文档"或"模板"？

**可能原因**：

- 文件类型不被识别。
- 文件格式不支持。
- 文件被错误分类。

**解决方法**：

- 确认扩展名是 .docx（不要用 .doc）。
- 检查文件是否可以正常打开。
- 通常 TestAgent 通过文件名后缀和文件内容识别。
- 如果还是无法识别，可以在对话中明确说明"这是需求文档"或"这是模板"。

### 7. 章节确认页面看不到任何章节？

**可能原因**：

- 模板无法解析。
- 模板没有标题层级。
- 模板文件损坏。

**解决方法**：

- 确认模板使用了 Word 标题样式。
- 在【我的模板】中预览模板，看是否识别到章节。
- 必要时重新上传模板。

### 8. 自动审查频繁标记高风险，怎么办？

**可能原因**：

- 需求文档缺少验收标准。
- 模板设计不够清晰。
- 触发了审查规则。

**解决方法**：

- 补充需求文档的验收标准。
- 简化模板结构。
- 让人工处理高风险章节。
- 参考 [如何提高测试方案生成质量](/help/article/improve-generation-quality)。

### 9. 生成的结果章节之间内容不一致？

**可能原因**：

- 多个文档版本冲突。
- 模板章节命名相似但含义不同。
- 资料中包含旧项目数据。

**解决方法**：

- 检查资料版本号，保留最新版本。
- 重新设计模板章节命名。
- 清理资料中的旧数据。

### 10. 导出 Word 后排版混乱？

**可能原因**：

- 模板包含复杂排版。
- 触发了格式丢失确认（但被忽略）。

**解决方法**：

- 简化模板（避免合并单元格、跨页大表）。
- 在导出阶段注意是否有"格式丢失确认"弹窗。
- 选择【接受】保留当前结果，或【重新尝试】用低保真模式。

## 三、模板相关

### 11. 上传模板后识别错误？

**可能原因**：

- 模板没有用 Word 标题样式。
- 标题层级混乱。
- 章节命名模糊。

**解决方法**：

- 用 Word 打开模板，确认标题用了样式。
- 参考 [如何设计适合 TestAgent 的模板](/help/article/template-design) 调整。
- 重新上传。

### 12. 我的模板里有些"已发布"，有些"未发布"，有什么区别？

**说明**：

- **未发布**：仅你自己可用。
- **已发布**：出现在模板市场，团队成员也能看到。

切换发布状态：在【我的模板】→【更多】→【发布 / 取消发布】。

### 13. 模板能修改吗？

**说明**：

- 不能直接编辑已上传模板的内容。
- 可以下载后修改，重新上传为新版本。
- 元数据（名称、描述、标签）可以编辑。

### 14. 上传模板后多久可以使用？

**说明**：

- 上传后立即可用。
- 预览生成需要数秒。
- 复杂模板可能需要更长时间。

### 15. 模板市场里的模板可以下载吗？

**说明**：

- 已保存的模板可以下载。
- 未保存的模板只能预览。

## 四、项目与对话

### 16. 项目和对话有什么区别？

**说明**：

- **对话**：一次独立的聊天，有自己的消息历史。
- **项目**：多个对话的容器，共享资料、知识库、指令。

详见 [什么是项目](/help/article/what-is-project)。

### 17. 删除项目会删除哪些内容？

**说明**：

- 项目本身被删除。
- **项目中的对话**：变回独立对话，消息历史保留。
- **项目资料**：解除关联，但不会删除资料库原文件。
- **项目产物**：保留在资料库的"系统生成"分类下。

### 18. 项目内的对话可以移出项目吗？

**说明**：

- 可以。在对话的【更多】菜单中选择【移出项目】。
- 移出后该对话变回独立对话。
- 不影响对话的消息历史。

### 19. 项目资料与资料库文件冲突怎么办？

**说明**：

- 项目资料是从资料库关联的，是同一份文件。
- 项目资料只是引用，不复制。
- 修改项目资料会影响资料库原文件。
- 项目内删除资料不会影响资料库原文件。

### 20. 项目内的产物会出现在资料库吗？

**说明**：

- 是的。所有系统生成的产物都会归档到资料库。
- 在资料库的"系统生成"分类下可看到。
- 项目资产页提供更结构化的视图。

## 五、资料库

### 21. 资料库的文件可以分享给团队成员吗？

**说明**：

- 团队文件默认对团队成员可见。
- 个人文件仅自己可见。
- 也可以通过"分享链接"对外分享（需要权限）。

### 22. 删除的文件能恢复吗？

**说明**：

- 软删除（移到"最近删除"）：30 天内可恢复。
- 永久删除（从"最近删除"彻底删除）：无法恢复。

详见 [管理资料库文件](/help/article/manage-library-files)。

### 23. 资料库的存储空间是多少？

**说明**：

- 个人版：通常 5–10 GB。
- 团队版：通常 100 GB+。
- 具体配额以系统显示为准。

### 24. 上传文件后预览失败？

**可能原因**：

- 文件格式异常。
- 文件已加密。
- 文件太大。
- 服务端临时故障。

**解决方法**：

- 用 Word 重新保存文件再上传。
- 取消文件加密。
- 压缩大文件后重试。

## 六、知识库

### 25. 知识库和资料库有什么不同？

**说明**：

- **资料库**：单个文件柜，适合"读完整文件"。
- **知识库**：企业知识检索系统，适合"找相关片段"。

详见 [什么是知识库](/help/article/what-is-knowledge)。

### 26. 如何验证知识库检索是否生效？

**方法**：

- 在【知识库】→【检索测试】中输入查询。
- 选择要测试的知识库。
- 查看返回的命中片段。

如果检索不生效：

- 检查知识库连接。
- 检查文档是否启用。
- 检查标签过滤是否过严。

### 27. 知识库检索结果不准确？

**可能原因**：

- 分片质量不高。
- 标签体系混乱。
- Top-K 与阈值设置不当。

**解决方法**：

- 调整分片方法与参数。
- 重新设计标签体系。
- 通过【检索测试】调整参数。

## 七、产物与下载

### 28. 任务完成后在哪里下载 Word？

**入口**：

- 聊天界面 → 任务完成卡片 → 【下载 Word】。
- 项目资产页 → 找到产物 → 【下载】。
- 资料库 → 系统生成 → 找到文件 → 【下载】。

### 29. 下载的 Word 文件名是什么？

**说明**：

- 通常是 `<需求标题>-<时间戳>.docx`。
- 例如 `测试方案-采购审批-v2-20260917.docx`。
- 可以重命名后再下载。

### 30. 下载的 Word 能用 WPS 打开吗？

**说明**：

- 可以。.docx 是 Office Open XML 标准格式。
- WPS、Pages、LibreOffice 都兼容。
- 部分复杂排版在非 Word 客户端可能略有差异。

### 31. 多个测试方案如何管理？

**建议**：

- 文件命名带上版本号：`测试方案-采购审批-v2.docx`。
- 按项目归档。
- 维护版本说明文档。
- 用 Git/SVN 管理版本。

## 八、错误处理

### 32. 任务一直处于"等待确认"状态？

**可能原因**：

- 用户没有在界面上提交章节确认。
- 用户提交了但系统没有接收到。

**解决方法**：

- 检查聊天界面是否有章节确认卡片。
- 如果有，确认后点击【开始生成】。
- 如果没有，等待或刷新页面。

### 33. 任务失败，如何排查？

**排查步骤**：

1. 查看任务失败原因（界面或日志）。
2. 检查 LLM 连通性。
3. 检查文件是否可访问。
4. 检查模板是否正确。
5. 取消任务后重新发起。

### 34. 自动审查结论与人工判断冲突？

**说明**：

- 自动审查只是辅助，不会强制结论。
- 人工判断优先。
- 如果自动审查频繁误判，反馈给团队以改进规则。

### 35. 服务端报错如何处理？

**排查步骤**：

1. 记录错误码与提示。
2. 查看日志（如果可访问）。
3. 重试一次。
4. 联系管理员。

## 九、性能与额度

### 36. 一次生成需要多长时间？

**说明**：

- 单章节生成：30 秒到 2 分钟。
- 完整 10 章节方案：5–15 分钟。
- 复杂需求或大资料可能更长。

### 37. 生成会消耗 LLM 额度吗？

**说明**：

- 是的，每次 LLM 调用都消耗额度。
- 知识库检索也消耗少量额度。
- 自动审查、修复、导出也会消耗。
- 详细额度可在【系统设置】查看。

### 38. 如何减少额度消耗？

**方法**：

- 用同一份模板生成，避免重复解析。
- 上传清晰的资料，避免 AI 反复"猜测"。
- 在项目内复用资料，避免重复上传。
- 用知识库减少 AI 自己"补充"的工作量。

## 十、最佳实践

### 39. 第一次使用 TestAgent，应该从哪里开始？

**建议路径**：

1. 完成系统设置（LLM、图像能力）。
2. 从模板市场保存一份通用模板。
3. 用一份简单需求试生成。
4. 阅读自动审查结论，下载 Word。
5. 熟悉后逐步扩展到项目、知识库。

### 40. 如何让团队快速上手？

**建议**：

- 准备一份团队级模板（统一规范）。
- 整理常见需求文档结构（培训用）。
- 让新成员先用模板市场保存的模板试生成。
- 定期 review 团队的测试方案，提炼最佳实践。

### 41. TestAgent 适合做测试用例吗？

**说明**：

- 当前版本主要生成测试方案。
- 测试用例可结合其他工具完成。
- 测试方案评审通过后，建议用专门工具设计测试用例。

### 42. 生成的方案可以直接作为最终方案吗？

**说明**：

- 不建议。TestAgent 提供的是"草稿"。
- 必须经过测试人员人工复核。
- 关键业务规则、边界条件、测试数据需要人工补充。

详见 [能力边界](/help/article/capability-boundaries)。

### 43. 多久应该升级模板？

**建议**：

- 每季度 review 一次模板。
- 业务类型新增时增加对应章节。
- 团队规范变化时调整模板。
- 收集使用反馈，定期优化。

### 44. 遇到文档中没有的问题怎么办？

**建议**：

- 在团队内部反馈。
- 联系 TestAgent 管理员。
- 提交 issue 或反馈邮件。
- 已知问题会更新到本帮助文档。
