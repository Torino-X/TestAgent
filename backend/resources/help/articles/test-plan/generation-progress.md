# 如何查看生成过程

测试方案生成是流式、可观察的过程。本节帮助你理解任务进度卡上每个状态、每个工具调用的含义，并知道何时该介入、何时该等待。

## 任务进度卡

点击聊天输入框上方的任务进度卡，可以展开任务详情。卡片包含：

- **总体进度**：已完成章节数 / 总章节数。
- **当前阶段**：解析需求、解析模板、知识库检索、章节生成、自动审查、导出 Word 等。
- **章节状态列表**：每个章节的实时状态。

## 章节状态机

每个章节会经历以下状态：

```
待生成 ──► 生成中 ──► 已生成 ──► 自动审查
                              │
                              ├── 通过 ──► 已完成
                              └── 失败 ──► 自动修复 ──► 重新审查
                                                   │
                                                   ├── 通过 ──► 已修复
                                                   └── 失败 ──► 需人工介入
```

| 状态 | 含义 | 你需要做什么 |
| --- | --- | --- |
| 待生成 | 章节尚未开始处理 | 等待 |
| 生成中 | LLM 正在写这一章 | 等待 |
| 已生成 | 内容已写入，可读 | 可点击章节查看初稿 |
| 自动审查 | 系统检查章节质量 | 等待 |
| 已修复 | 自动修复了一轮 | 等待 |
| 已完成 | 章节定稿 | 进入复核环节 |
| 需人工介入 | 自动审查认为需要人工处理 | 查看具体原因 |

## 实时工具调用

任务进度卡下方会显示实时的工具调用流，按时间顺序列出：

```
14:32:01  [knowledge_search] 检索「采购审批」相关业务规则
14:32:08  [llm_call] 调用 chat 能力，生成「测试范围」章节
14:32:15  [section_review] 审查「测试范围」
14:32:20  [section_review_passed] 通过
14:32:21  [llm_call] 调用 chat 能力，生成「测试策略」章节
...
```

每条工具调用都会显示：

- **工具名**：knowledge_search、llm_call、section_review、doc_export 等。
- **关键参数**：检索关键词、章节标题、参数摘要。
- **耗时**：单步执行时间。
- **结果摘要**：命中条数、生成字符数等。

## SSE 心跳与断线续传

为了让长任务保持连接，TestAgent 在没有事件时也会周期性发送心跳（keep-alive）。这意味着：

- 即使页面长时间没变化，连接仍然活跃。
- 意外刷新或断网后，重新打开聊天会从上次位置继续，已完成的章节不会丢失。
- 关闭聊天页面前不必担心"任务会停"——只要服务还在运行，任务就会继续。

> 注意：手动关闭浏览器或切换网络后，短时间内重连可以续上；如果服务端判定客户端长时间失联，任务可能进入"已暂停"状态，需要在界面恢复。

## 如何主动介入？

### 情况 1：发现某章节生成方向不对

点击【暂停任务】（如果出现），在对话中补充说明，然后【继续】。

### 情况 2：自动修复效果不理想

等待任务自然完成。完成后通过【修改章节】提具体修改要求。

### 情况 3：长时间没有进度

如果一个章节"生成中"超过 10 分钟没有更新，可能是 LLM 阻塞。建议：

- 检查【系统设置】中的模型连通性（点击"测试连接"）。
- 取消任务（页面提供【取消】按钮），调整后重新发起。

## 异常处理

### 任务失败

如果任务失败，界面会显示失败原因。常见原因：

- **LLM 配置错误**：到【系统设置】检查 API URL、Key、模型名。
- **文件读取失败**：检查文件是否被删除或权限不足。
- **模板无法解析**：模板可能包含不支持的元素（如加密、宏）。
- **服务异常**：查看页面提示，重试或联系管理员。

### 自动审查"高风险"标记

如果自动审查认为某个章节"高风险"，并不意味着生成失败。可能是：

- 章节依赖了不完整的上下文（部分需求描述模糊）。
- 章节内容触发了审查规则（如缺少测试点）。

处理方式：

- 任务完成后阅读自动审查意见。
- 对高风险章节人工复核，必要时通过"修改章节"调整。

## 完成后的查看入口

任务完成后，"任务完成卡片"会列出：

- **章节摘要**：每个生成章节的一句话概述。
- **自动审查结论**：整体审查意见。
- **下载 Word**：下载产物。
- **查看完整方案**：打开产物预览。

如果是在项目内生成的对话，对话本身和产物会自动归档到项目资产页。
