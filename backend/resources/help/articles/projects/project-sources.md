# 项目资料

项目资料是项目级共享的文件集合。本节介绍如何上传、关联、删除、引用项目资料，以及项目资料与资料库、对话附件的关系。

## 一句话理解

**项目资料 = 项目级共享的"上下文文件"。**

项目内所有对话都能引用项目资料，不需要每次重新上传。

## 项目资料的两种来源

### 1. 上传到项目

直接把新文件传到项目：

- 入口：项目输入框的附件按钮，或项目资料标签的【添加来源】。
- 适合：项目专属的文件（如项目特有的 PRD、设计稿）。
- 上传后文件副本存在于项目内，仅本项目使用。

### 2. 从资料库关联

把资料库中已有的文件关联到项目：

- 入口：项目资料标签 → 添加来源 → 从资料库选择。
- 适合：跨项目共享的文件（如公司通用规范）。
- 关联后资料库原文件仍存在，项目只是引用。

两种来源的项目资料在使用上没有区别。

## 资料角色

每份项目资料可以标记一个角色（source_role），便于检索和分类：

| 角色 | 用途 |
| --- | --- |
| requirement | 需求文档 |
| design | 设计文档、接口说明 |
| reference | 参考资料、规范、历史方案 |
| test_artifact | 测试相关产物 |
| other | 其他 |

角色的主要作用是：

- **视觉标识**：在资料列表中显示不同颜色或图标。
- **检索权重**：AI 在生成时按角色调整引用顺序（例如 requirement 优先于 other）。
- **归档分类**：方便团队按角色筛选资料。

## 如何上传项目资料

### 入口 1：项目输入框附件按钮

在项目详情页输入框左侧点击【附件】按钮：

1. 弹出文件选择器或资料库选择器。
2. 选择"上传新文件"或"从资料库选择"。
3. 文件被添加到本次对话的临时附件。
4. 点击【作为项目资料】按钮（如果出现）将其升级为项目资料。

### 入口 2：项目资料标签

1. 切换到【项目资料】标签。
2. 点击【添加来源】按钮。
3. 选择"上传新文件"或"从资料库选择"。
4. 选择资料角色。
5. 点击【确认】。

### 支持的文件格式

与资料库一致：.docx、.pdf、.md、.txt、图片等。

## 如何从资料库关联

1. 在项目资料标签点击【添加来源】。
2. 选择【从资料库选择】。
3. 在资料库弹窗中浏览或搜索文件。
4. 选择目标文件，点击【关联】。
5. 选择资料角色（requirement / design / reference / other）。
6. 点击【确认】。

关联后的文件会出现在项目资料列表中，带上"已关联"标识。

## 资料列表

项目资料标签页展示所有项目资料，每行包含：

- 文件图标（按类型显示）。
- 文件名与简短描述。
- 角色标签（彩色标签）。
- 上传/关联时间。
- 操作按钮（预览、移除）。

### 资料预览

点击资料卡片可以预览：

- 文档按章节结构渲染。
- 图片直接显示。
- PDF 渲染为可读视图。

预览不消耗 LLM 额度。

### 资料移除

把资料从项目中解除关联：

1. 点击资料的【移除】按钮。
2. 确认移除。

:::warning
移除项目资料不会删除资料库原始文件。如果要彻底删除，需要到资料库操作。
:::

## 项目资料的引用机制

### 自动引用

项目内所有对话自动引用所有项目资料作为上下文。无需在每次对话中重新上传或附加。

### 引用顺序

AI 在生成时按以下顺序考虑资料：

1. **本次对话上传的附件**（优先级最高）。
2. **项目资料**（按角色和文件大小）。
3. **知识库检索结果**（如果项目绑定了知识库）。
4. **项目指令**。

### 引用失败处理

如果项目资料被删除或无法访问：

- 对话发起时 AI 会提示"部分资料无法访问"。
- 可以补充上传资料或移除失效引用。
- 已生成的产物不受影响（已生成的内容已固化）。

## 项目资料的典型用法

### 用法 1：项目级 PRD

把项目的 PRD 上传到项目资料：

- 所有对话都可以引用。
- 后续的测试方案、修改都基于同一份 PRD。
- PRD 更新后只需替换一份资料。

### 用法 2：跨项目规范

把团队级规范（如"性能测试规范"）关联到多个项目：

- 避免每个项目都重新上传。
- 规范更新后所有项目自动生效（关联的资料库文件更新）。

### 用法 3：设计文档集

把多个设计文档（架构、数据库、接口）一起上传：

- AI 在生成时可以跨文档交叉引用。
- 减少"AI 漏掉某份文档"的情况。

### 用法 4：历史方案参考

把上一版本的测试方案关联到当前项目：

- AI 可以参考历史方案的结构与覆盖度。
- 帮助保持团队方案的一致性。

## 项目资料与"对话附件"的区别

| 维度 | 项目资料 | 对话附件 |
| --- | --- | --- |
| 范围 | 整个项目 | 仅本次对话 |
| 持续性 | 持续存在 | 对话结束仍可见，但不跨对话共享 |
| 引用方式 | 自动引用 | 仅本对话 |
| 适合 | 跨对话复用 | 一次性、临时性 |

**实践建议**：

- 项目级文档（PRD、规范）放在【项目资料】。
- 临时性文件（某个需求特有的截图）放在【对话附件】。
- 不确定时优先放【项目资料】（可以随时移除，不会丢文件）。

## 资料数量与性能

### 数量建议

- 项目资料数量建议 3–15 份。
- 太多会增加 AI 处理时间，可能让上下文超限。
- 太少可能覆盖不全。

### 单份文件大小

- 单份文件建议不超过 30 MB。
- 过大文件可能让上传变慢或生成超时。

### 资料去重

避免上传重复资料：

- 同一份 PRD 不要在多个对话中重复上传。
- 同类规范可以从资料库关联，避免冗余。

## 与"知识库"的区别

| 维度 | 项目资料 | 项目知识库 |
| --- | --- | --- |
| 形式 | 文件 | 企业知识库 |
| 检索方式 | 全文 | 向量/关键词检索 |
| 适用 | 完整文件 | 长文档检索片段 |
| 设置位置 | 项目资料标签 | 项目设置 → 知识库 |

项目资料更适合"完整的文件"，项目知识库更适合"长文档库的片段检索"。
