# 项目产物

项目产物是项目内所有生成的测试方案、审查报告与中间产物。本节介绍产物的分类、查看、管理、归档流程。

## 一句话理解

**项目产物 = 项目内"产出物"的集中归档。**

与【资料库】的区别：

- **资料库**：所有文件的总览（含用户上传、系统生成）。
- **项目产物**：仅项目内生成的产物，按项目分组。

## 产物分类

项目内生成的产物通常包含：

| 类型 | 典型场景 |
| --- | --- |
| 测试方案 | 完整的测试方案 Word 文件 |
| 审查报告 | 自动审查输出的报告 |
| 中间产物 | 章节预览、修改记录、版本对比 |

未来可能扩展：

- 测试用例（待支持）。
- 缺陷分析报告（待支持）。
- 性能测试报告（待支持）。

## 产物入口

### 入口 1：项目详情页 → 测试资产标签

项目详情页的第三个标签是【测试资产】，列出项目内所有产物。

### 入口 2：聊天界面 → 任务完成卡片

任务完成后，"任务完成卡片"上有"查看完整方案"和"下载 Word"按钮。

### 入口 3：资料库 → 系统生成筛选

所有系统生成的产物也会出现在资料库的"系统生成"分类下，按时间倒序排列。

## 产物列表

测试资产标签页展示：

- **产物名称**（按需求标题自动命名）。
- **类型**（测试方案 / 审查报告）。
- **生成时间**。
- **关联消息**（触发该产物的对话消息）。
- **操作菜单**（预览、下载、重命名、删除）。

### 排序与筛选

- 默认按生成时间倒序（最新的在前）。
- 可以按类型筛选（只看测试方案 / 只看审查报告）。
- 支持搜索（按名称）。

## 查看产物

### 预览

点击产物卡片打开预览页：

- 按章节结构渲染。
- 显示自动审查结论。
- 显示修改历史（如果有）。

预览是只读的，所有修改都需要回到原对话提修改要求。

### 下载

点击【下载】按钮，下载 .docx 文件：

- 文件名通常是 `<需求标题>-<时间戳>.docx`。
- 下载后可独立使用 Word/WPS 打开。

## 产物的版本管理

### 一次任务对应一份产物

每个测试方案生成任务完成后，会在资产页生成一份产物。同一对话多次生成会产生多份产物。

### 修改记录

对已生成的产物提修改要求后，修改会作为**增量任务**处理。产物本身的版本号会更新，但产物仍然是同一份（覆盖更新）。

如需保留修改历史，建议：

- 下载旧版本作为本地归档。
- 在文档说明中维护版本历史。

### 同一需求多个方案

如果同一需求想用不同模板生成多份方案：

- 在不同对话中分别发起任务。
- 项目资产页会列出多份产物。
- 通过命名或描述区分。

## 产物的元数据

每份产物记录以下元数据：

- 名称
- 类型（测试方案 / 审查报告）
- 生成时间
- 关联对话 ID
- 关联消息 ID
- 关联任务 ID
- 模板来源（用了什么模板）
- 任务引擎（LangGraph / Legacy）
- 状态（生成中 / 已完成 / 已失败 / 已取消）

元数据用于：

- 在资产列表中显示。
- 排查问题时定位。
- 跨产物对比。

## 产物的管理操作

### 重命名

点击产物的【更多】菜单 → 【重命名】：

- 修改产物在资产页的显示名。
- 不影响实际文件名（下载时仍按原始命名）。
- 重命名建议带上版本号或日期。

### 删除

点击产物的【更多】菜单 → 【删除】：

- 产物从项目资产页移除。
- 移至资料库的"最近删除"分类，可在 30 天内恢复。
- 30 天后自动永久删除。

### 永久删除

- 在资料库的"最近删除"中可以执行永久删除。
- 永久删除后无法恢复。

:::warning
删除项目本身时，项目中的对话会变回独立对话，但已生成的产物会保留在资料库，不会被删除。
:::

## 产物的协作

### 团队共享

项目内的产物对团队成员可见（取决于权限设置）。团队成员可以：

- 查看产物内容。
- 下载产物文件。
- 在原对话中提修改要求（需要权限）。

### 评审与归档

下载后的产物可进入团队评审流程：

- 上传到团队文档系统。
- 附加到工单。
- 邮件发送给评审人。

TestAgent 不替你完成这些动作，但产物的命名、结构、文件格式都为后续评审做好了准备。

## 产物与对话的关系

每个产物都与产生它的对话和消息相关联：

- 在产物列表中点击【关联消息】可以跳转到对应的对话消息。
- 在对话中点击产物卡片可以跳转到产物预览。

这种关联便于：

- 看到产物时回顾当时的对话上下文。
- 修改产物时直接回到对话。
- 排查问题时定位到具体任务。

## 产物对比（多版本）

如果同一需求有多份产物，可以：

- 在资料库中并排打开两份 Word 文件对比。
- 通过命名约定（v1、v2、v3）快速区分。
- 在文档说明中维护版本历史。

TestAgent 当前不提供"产物版本对比"功能，建议：

- 下载多份产物到本地，用 Word 的"比较文档"功能对比。
- 或在文档说明中人工记录差异。

## 产物的清理与归档

### 定期清理

项目结束或阶段性目标达成后，可以：

- 保留关键产物（核心测试方案）。
- 删除中间产物（草稿、试验性方案）。
- 把保留的产物下载到本地作为归档。

### 长期归档

对于重要项目的所有产物，建议：

- 在团队文档系统中建立项目归档目录。
- 把产物按"测试方案 / 审查报告 / 中间产物"分类存放。
- 维护版本说明文档。
