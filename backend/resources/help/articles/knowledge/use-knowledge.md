# 使用与检查知识库

知识库的设置与维护是 TestAgent 的高阶功能。本节详细介绍创建知识库、导入文档、配置标签、检索测试的完整流程。

## 知识库相关页面

### 入口

- **侧边栏 → 知识库**

### 页面标签

知识库页面提供 7 个标签：

| 标签 | 内容 |
| --- | --- |
| 概览 | 知识库列表与统计 |
| 知识库 | 知识库列表与新建 |
| 文档 | 文档管理与上传 |
| 检索测试 | 测试检索效果 |
| 标签 | 标签管理 |
| 分片 | 分片管理与编辑 |
| 设置 | 连接配置 |

## 第 1 步：配置知识库连接

### 入口

知识库页面 →【设置】标签。

### 配置项

#### 连接配置

- **API URL**：知识库服务的访问地址。
- **API Key**：访问知识库的凭证（密码框输入）。
- **测试连接**：点击【测试连接】验证配置是否正确。

#### 测试连接结果

测试连接会返回：

- ✅ 成功：列出可用的知识库数量。
- ❌ 失败：显示错误码与原因。

### 常见失败原因

- API URL 错误（协议、端口、路径）。
- API Key 错误或过期。
- 网络问题（VPN、防火墙）。
- 服务端临时故障。

## 第 2 步：创建知识库

### 入口

知识库页面 →【知识库】标签 →【新建知识库】。

### 创建参数

#### 基础信息

- **名称**：知识库显示名。
- **描述**：知识库用途说明。
- **分片方法**：选择 general / parent_child / qa。

#### 分片参数

- **块大小**：每片包含多少字符或 token。
- **块重叠**：相邻块的重叠量（保持上下文）。
- **按何种单位切分**：token / chars / sentences。

#### 解析参数

- **文件解析类型**：auto / pdf / docx / txt / md / html。
- **图片解析**：off / ocr / vision。
- **嵌入模型**：用于向量化的模型。

### 创建后

- 知识库出现在列表中。
- 显示知识库 ID、状态、分片数。

## 第 3 步：导入文档

### 入口

知识库页面 →【文档】标签 →【上传文档】。

### 导入方式

#### 上传文件

- 选择目标知识库。
- 上传一个或多个文档文件。
- 系统开始解析、分片、嵌入、索引。

#### 导入结构

如果已有结构化数据（不在 TestAgent 中），可以通过"导入结构"批量上传分片数据。

### 文档状态

每个导入的文档有以下状态：

| 状态 | 含义 |
| --- | --- |
| 解析中 | 文档正在被解析 |
| 分片中 | 文档被切分为多个分片 |
| 嵌入中 | 分片正在被向量化 |
| 索引中 | 向量正在被加入索引 |
| 已启用 | 文档可被检索 |
| 已禁用 | 文档存在但不参与检索 |
| 失败 | 处理失败，可查看错误日志 |

### 文档管理

- **启用 / 禁用**：控制文档是否参与检索。
- **删除**：从知识库中移除文档。
- **查看文档**：浏览文档内容。
- **预览 URL**：获取文档预览链接。
- **下载 URL**：获取文档下载链接。

## 第 4 步：管理标签

### 标签的作用

标签用于：

- 给文档/分片打语义标签。
- 检索时按标签过滤。
- 团队级标签分类。

### 创建标签

知识库页面 →【标签】标签 →【新建标签】：

- 标签名。
- 颜色（可选）。
- 描述。

### 应用标签

标签可以应用到：

- **文档级别**：标签应用到整个文档。
- **分片级别**：标签应用到具体分片。

应用方式：

- 在文档管理页 → 选择文档 → 批量打标签。
- 在分片管理页 → 选择分片 → 批量打标签。

### 检索时按标签过滤

在【检索测试】标签中：

- 输入查询关键词。
- 选择要过滤的标签。
- 系统只返回带这些标签的分片。

## 第 5 步：检索测试

### 入口

知识库页面 →【检索测试】标签。

### 检索参数

- **查询关键词**：要检索的问题或词组。
- **知识库**：选择检索的知识库。
- **标签过滤**：选择要包含的标签。
- **Pre-Rerank Limit**：粗排阶段返回的最大分片数。
- **Top-K**：精排后返回的最大分片数。
- **Score 阈值**：分数低于阈值的分片被过滤。

### 检索结果

- **命中的分片列表**：每个分片显示文档来源、内容摘要、相似度分数。
- **关联分片**：如果有图谱关联，显示相邻分片。
- **导出**：可导出检索结果为 JSON 或 CSV。

### 检索测试的用途

- 验证知识库内容是否被正确索引。
- 调整 Top-K 与阈值，找到最佳参数。
- 验证标签过滤是否生效。

## 第 6 步：分片管理

### 入口

知识库页面 →【分片】标签。

### 分片操作

- **查看分片**：浏览分片内容。
- **编辑分片**：修改分片文本。
- **更新分片**：触发重新嵌入。
- **删除分片**：从知识库移除。
- **关联相邻分片**：建立图谱关联。
- **添加分片问题**：为分片添加标准问。
- **管理分片图片**：更新/删除分片关联的图片。

### 何时需要编辑分片？

- 分片切分不理想（例如一句话被切到两半）。
- 内容有错别字或格式问题。
- 需要补充额外信息。

### 分片质量的影响

- 切分质量差 → 检索召回率低。
- 内容错误 → AI 引用错误信息。
- 缺少关键信息 → 检索不到相关内容。

## 第 7 步：图谱关联

### 入口

知识库页面 →【文档】标签 →【重建图谱】。

### 图谱的作用

- 建立分片之间的关联。
- 检索时返回"邻居"分片，提升召回率。

### 重建时机

- 大量新增文档后。
- 检索召回率明显下降时。

### 重建成本

- 图谱重建耗时较长（按文档量）。
- 重建期间检索可能受影响。

## 第 8 步：检索问答

知识库问答（在生成测试方案之外）：

- 用户问业务问题。
- 系统检索知识库。
- AI 综合检索结果给出回答。

这种场景适用于：

- 客服、内部咨询。
- 业务规则问答。
- 历史项目参考。

## 知识库维护建议

### 内容质量优先

- 知识库的价值依赖内容质量。
- 低质量内容会让 AI 生成结果偏离。
- 定期 review 与清理。

### 标签体系设计

- 设计清晰的标签分类（例如"制度""规范""历史"）。
- 避免标签泛滥（每个分片不超过 5 个标签）。
- 标签名要语义明确。

### 分片策略

- 通用文档用 general 分片。
- 长文档用 parent_child（保留层级）。
- 问答类内容用 qa。

### 检索参数调优

- 通过【检索测试】调整 Top-K 与阈值。
- 找到召回率与精度的平衡点。

## 常见问题

### 检索召回率低？

- 检查文档是否启用。
- 检查分片是否正确生成。
- 调整 Top-K 与阈值。
- 重建图谱。

### 检索结果不准确？

- 检查标签过滤是否过严。
- 检查分片内容是否正确。
- 调整查询关键词。

### 知识库对接失败？

- 检查 API URL 与 Key。
- 测试网络连通性。
- 联系知识库服务方。
