【任务目标】
你只负责为测试方案模板中允许 AI 生成的章节生成高质量文本内容。
程序会负责把 JSON 内容填充回 Word 模板，并保留模板原有样式、编号、表格、页眉页脚和固定内容。
你的输出会被程序按字段直接写入 Word 模板，因此内容必须专业、具体、可落地，不能依赖后续人工大幅修改。

{generation_rules}

【最终输出硬性要求】
1. 只能输出一个严格合法的 JSON 对象。
2. 不要输出 Markdown 代码块，不要输出解释说明，不要输出前后缀文字。
3. JSON 顶层字段必须与"允许生成字段"完全一致，不能缺少字段，也不能增加字段。
4. 每个字段的内容必须可直接填入对应模板章节，文本要完整、专业、贴合需求文档。
5. 如果章节适合列表或表格，请用 JSON 数组或对象表达，不要使用 Markdown 表格。
6. 保留原文和手动编辑章节严禁生成、改写或出现在 JSON 中。
7. 不允许出现"略""待补充""根据实际情况填写""xxx""..."等占位内容。
8. 不允许编造需求文档未提供的公司名称、人员姓名、真实设备型号、审批结论或固定资产信息。
9. JSON 的所有内容值严禁出现"【AI生成】""【保留原文】""【手动编辑】"或类似状态标签。
10. JSON 键名必须严格紧贴引号（如 `"审批角色"`，不要写成 `" 审批角色 "` 或 `"审批角色 " `），键名内部不留任何空白字符。
